# Docs / preview assets

This folder holds the screenshots and GIF shown in the project README.

| File | Purpose | Generated by |
| --- | --- | --- |
| `preview.png` | Static screenshot of the landing page (1440 × 900) | `npm run capture` |
| `demo.webm` | Short Playwright-recorded interaction clip | `npm run capture` |
| `demo.gif` | Same demo, GIF-encoded for GitHub README | `npm run capture` (ffmpeg) |

## Regenerate

```bash
npm run build
npm run capture
```

The capture script (`scripts/capture-showcase.mjs`):

1. Builds `dist/` if it's missing.
2. Spawns `vite preview` on port `4173` and waits for it.
3. Launches headless Chromium with a 1440 × 900 viewport.
4. Takes `docs/preview.png` from the default landing state
   (`#cozy-study/classic/append`).
5. Records `docs/demo.webm` while running this scripted flow:
   - Open `#k-pop-comeback/emoji/append`
   - Click **Copy JSON** → wait for "Copied!"
   - Click the **Try this personality** button on the Cat on Keyboard card
   - Switch to the **Kaomoji** style
   - Click **Copy share link** → wait for "Link copied!"
6. Converts the recording to `docs/demo.gif` via ffmpeg (`fps=12`,
   `scale=1200:-1`). If the resulting GIF is over 5 MB, retries at `fps=10`,
   `scale=900:-1`.

Stops the preview server and closes the browser on exit (or on error).

## Requirements

- Node 18.18+ (Node 20+ recommended).
- Playwright Chromium — installed once with:
  ```bash
  npx playwright install chromium
  ```
- **ffmpeg** (optional, for GIF conversion). If ffmpeg is missing the script
  still writes `demo.webm` and skips the GIF step with a warning.

## Environment overrides

| Variable | Purpose |
| --- | --- |
| `CAPTURE_BASE_URL` | Use an already-running server instead of spawning `vite preview`. Example: `CAPTURE_BASE_URL=http://127.0.0.1:5173/ npm run capture`. |
| `CAPTURE_PORT` | Port for the auto-spawned `vite preview` (default `4173`). |

## Manual alternatives (without the script)

If you'd rather record by hand:

### macOS Screenshot.app + gifski

```bash
brew install gifski
```

1. `Cmd-Shift-5` → Record Selected Portion → record the demo flow.
2. Save the `.mov` somewhere.
3. Convert:

```bash
gifski input.mov -o docs/demo.gif --fps 12 --width 1200
```

### Kap / CleanShot

Export directly to GIF, drop it into `docs/demo.gif`.

### Suggested demo flow (~6–8s)

1. Open the live demo.
2. Click **K-pop Comeback** in the museum.
3. In the studio, toggle to **Emoji**.
4. Click **Copy JSON**.
5. Click **Cat on Keyboard** in the museum.
6. Toggle to **Kaomoji**.
7. Click **Copy share link**.

Aim for under 8 seconds and under 5 MB.

## Reducing GIF size manually

If you tweak the demo and the GIF balloons, re-run ffmpeg by hand:

```bash
ffmpeg -y -i docs/demo.webm -vf "fps=10,scale=900:-1:flags=lanczos" docs/demo.gif
```

Drop `fps` or `scale` further if you need to land under a stricter budget.
